# Formatting Guide

## Document Formatting

### Font
- **Standard font**: Times New Roman, Arial, or Calibri
- **Size**: 11-12 pt for body text
- **Headers**: 14-16 pt, bold

### Spacing
- **Line spacing**: 1.5 or double-spaced (usually specified)
- **Margins**: 1" all around (unless specified otherwise)
- **Paragraph indentation**: 0.5" or use first-line indent

### Headers and Subheaders
```
Main Header (14pt, Bold)

Subheader (12pt, Bold)

Sub-subheader (11pt, Bold Italic)
```

## Citation Formatting

### In-Text Citations

**APA**: (Author, Year)
- (Smith, 2024)
- Smith (2024) argues that...

**MLA**: (Author Page)
- (Smith 42)
- Smith argues that (42)

### Reference List Format

**APA**:
```
Author, A. A. (Year). Title of work. Publisher.
Author, B. B. (Year). Title of article. Journal Name, Volume(Issue), pages.
```

**MLA**:
```
Author. "Title of Work." Publisher, Year.
Author. "Title of Article." Journal Name, vol. X, no. Y, Year, pp. XX-XX.
```
