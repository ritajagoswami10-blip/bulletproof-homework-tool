# Assignment Completion Checklist

## Planning Phase
- [ ] Read assignment prompt completely
- [ ] Identify key requirements
- [ ] Check due date and submission format
- [ ] Note any grading rubric criteria
- [ ] Plan timeline for completion

## Research/Preparation Phase
- [ ] Gather necessary resources
- [ ] Read relevant materials
- [ ] Take organized notes
- [ ] Identify sources
- [ ] Create outline/plan

## Creation Phase
- [ ] Start early (avoid last-minute rush)
- [ ] Follow outline/plan
- [ ] Complete core requirements
- [ ] Add supporting details
- [ ] Save work frequently
- [ ] Create backups

## Review Phase
- [ ] Read through entire work
- [ ] Check for completeness
- [ ] Verify all requirements met
- [ ] Check formatting/style
- [ ] Proofread for errors
- [ ] Get peer feedback if possible

## Revision Phase
- [ ] Fix identified issues
- [ ] Improve clarity
- [ ] Enhance content quality
- [ ] Add citations/references
- [ ] Final proofread
- [ ] Format for submission

## Submission Phase
- [ ] Double-check file name/format
- [ ] Verify file is not corrupted
- [ ] Submit before deadline
- [ ] Confirm submission receipt
- [ ] Keep copy for records

## Post-Submission
- [ ] Review feedback when received
- [ ] Identify areas for improvement
- [ ] Keep assignment for portfolio
- [ ] Learn from instructor comments
