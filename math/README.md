# Math & Problem Sets 🧮

Step-by-step solutions for math problems, formulas, and problem-solving strategies.

## Topics Covered

- **Algebra** - Equations, polynomials, functions
- **Geometry** - Shapes, angles, proofs
- **Trigonometry** - Sines, cosines, applications
- **Calculus** - Limits, derivatives, integrals
- **Linear Algebra** - Matrices, vectors, systems
- **Statistics** - Probability, distributions, hypothesis testing
- **Physics** - Motion, forces, energy

## Problem-Solving Steps

1. **Read carefully** - Identify what you're given and what you need to find
2. **Identify formulas** - Which formulas apply?
3. **Set up** - Write out the equation or problem setup
4. **Solve** - Step by step
5. **Check** - Does the answer make sense?
6. **Interpret** - What does the answer mean?

## Common Mistakes to Avoid

✘ Forgetting units  
✘ Sign errors  
✘ Order of operations mistakes  
✘ Arithmetic errors  
✘ Not checking work  
✘ Misunderstanding the question  

## Tips

✅ Show all work  
✅ Label everything  
✅ Check your arithmetic  
✅ Use dimensional analysis  
✅ Estimate to see if answer is reasonable
